# Project verification

- Existing regression suite: `PYTHONPATH=third_party/FasterWAM/src:. .venv/bin/python -m pytest tests -q`. The current local `.venv` does not have FasterWAM installed as an editable package.
- Refined-policy fast tests: `.runtime/refined-venv/bin/python -m pytest tests/refined -q`.
- Refined runtime setup: `bash scripts/setup_refined.sh`; dependencies are isolated from the existing `.venv` and pinned in `requirements-refined.lock`.
- ComfyUI source is pinned under `.runtime/ComfyUI`. Keep integration changes in `wam_h3/refined`, not in upstream ComfyUI.
- On the current two-H100 PCIe host, CUDA 12.8 works with the explicitly enabled Comfy Kitchen Triton INT8 ConvRot backend. Direct GPU peer access is unavailable; stage transfers through pinned host memory.
- Refined video dimensions are width 768, height 384. Resize each camera independently to 384×384 before horizontal concatenation, external camera left and wrist camera right.
- Train and develop on official LIBERO only. Reserve LIBERO-Plus for OOD evaluation. Official Spatial HDF5s and their verified manifest live under `data/libero_official`; use `scripts/download_refined_libero.py` to reproduce the download from the official upstream HF mirror. Do not substitute the existing FastWAM derivative.
- Endpoint-conditioned generation artifacts must never enter causal policy caches. Real training requires generation review and verified official-data post-action alignment (`obs[t]` predicts `action[t+1]`).
- Official preprocessing: `.runtime/refined-venv/bin/python scripts/precompute_refined.py --variants minimal camera constraints physical`. Cameras are stored at 128×128; preserve the recorded RGB orientation and upscale each view to 384×384.
- Causal feature smoke: `.runtime/refined-venv/bin/python scripts/smoke_refined_models.py --input data/refined/official_spatial_smoke/episode_000000_camera.pt`. Require exact historical equality under prefix truncation and future perturbations.
- FlexAttention's separate full/partial-block traversal can change accumulation order with sequence length. The refined extractor deliberately combines nonempty blocks into chronological masked traversal with fixed 64×64 kernel tiles; do not replace this with the default full-block fast path without rerunning exact prefix tests.
- Policy cross-attention normalizes each selected hidden token before learned K/V projections because FL2VA hidden-state magnitudes vary strongly across depths. This is per-token normalization and does not mix temporal information.
- Training smoke: `.runtime/refined-venv/bin/python scripts/train_refined.py`; the Hydra config is `configs/refined_train.yaml` and existing LoRA training remains separate.
- Two-GPU stage profiling: `.runtime/refined-venv/bin/python scripts/measure_refined_pipeline.py --input data/refined/official_spatial_smoke/episode_000000_camera.pt --output runs/refined_action_policy/pipeline_profile_detailed.json`. This uses synthetic policy loss and no optimizer updates; keep it distinct from the official supervised training smoke. Optional stage timing synchronizes devices and can affect measured overlap.
- Checkpoint continuation uses `resume=<run>/step_000010 max_steps=11 output_dir=<new-run>`; `max_steps` is the total target step, not the number of additional updates. Use a fresh output directory to avoid appending metrics to a previous run. The shuffled chunk-budget trainer requires checkpoints with sampler state; legacy smoke checkpoints cannot resume that sampler.
- Mixed official data: `scripts/download_refined_libero.py --suites all --output data/libero_official_mixed` selects Spatial/Object/Goal/90/10, not an additional LIBERO-100 copy. Keep the old Spatial manifest separate so its episode IDs remain stable.
- `scripts/split_refined_libero.py` audits action and two-camera byte fingerprints, deduplicates episodes, and writes `data/refined/official_mixed_split.json`. Seed 0 gives 5,850 training and 650 validation episodes from 6,500 unique demonstrations, with 45/5 per task. LIBERO-10 is training data in this setup, not a held-out benchmark.
- Mixed preprocessing uses `scripts/precompute_refined.py --dataset data/libero_official_mixed --split-manifest data/refined/official_mixed_split.json --output data/refined/official_mixed --skip-existing`; disjoint workers use `--num-shards 2 --shard-index 0 --device 0` and `--shard-index 1 --device 1`. Keep validation prompt/noise fixed; training normalization excludes validation.
- `target_chunks=64` accumulates whole episodes and divides summed chunk-mean gradients by the actual chunk count before clipping. Mixed episodes have 2–16 chunks, so updates contain 64–79 chunks. Timed runs use `max_seconds=1800` plus a generous `max_steps` ceiling and `wandb.enabled=true`; active batches/validation finish gracefully, not via process termination.
